1 · What changed since the Jul 15 map

All four workflows were touched between Jul 16 and Jul 20. The wiring problems are mostly fixed; the copy problems mostly are not.

✓ Fixed in the rebuild

  • Missed Meetings dropped the one-off webhook. It now fires on the clinic-demo-no-show tag, and a second trigger for clinic-demo-canceled was added Jul 20 — cancellations finally get chased too. Re-entry is now allowed, so repeat no-shows re-enroll.
  • Post Signing moved off the starved "Closed" stage. It now fires when a deal enters Waiting for Patient Data / Eligibility — the onboarding bottleneck the old map flagged as the #1 silent stage. The welcome experience can actually run now.
  • Contract Sent got a guard branch. After the initial 3-day wait it checks the deal is still sitting in "Contract Sent" before sending anything — signed or dead deals exit silently. A backup clinic-contract-sent tag trigger was also added.
  • Monthly Check-in's manual dependency is now documented. A sticky note in the builder spells out that status-live must be applied by hand when a clinic goes live. Documented — but still manual (see issues).

✗ Still open

  • "[Link]" is still literal text in Missed Meetings emails 2 and 3 — and it's no longer hypothetical: the first full cohort (6 contacts) aged out of the chase with 0 replies and 0 rebooks.
  • Stop-on-reply is still OFF for Missed Meetings. A prospect who replies keeps getting chased by the rest of the sequence.
  • No from-name / from-email on any of the 10 emails — delivery still rides on account fallback settings.
  • Monthly Check-in still sends a placeholder email — [Month] and $[X] go out exactly as written if the tag is ever applied.
  • Post Signing still promises attachments it doesn't have, and still declares "you're live" on a blind Day-7 timer.
  • The old copy bugs survived: "Sections sometimes reads a little dense" typo and the {{business.name}} mix-up in Contract Sent.
